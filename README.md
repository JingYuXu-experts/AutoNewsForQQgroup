# 中东要闻推送

自动抓取中东主流媒体新闻 → DeepSeek 翻译编辑 → 推送到 QQ 群。
一个 exe，双击就用，不装 Python、不装任何运行库。

---

## 三步开始使用

### 1. 填密钥

打开软件 → 「设置」页，填两样东西：

| 项目 | 去哪拿 |
|---|---|
| **DeepSeek API Key** | [platform.deepseek.com](https://platform.deepseek.com) → API Keys → 创建 |
| **QQ 机器人 AppID / AppSecret** | [QQ 开放平台](https://q.qq.com) → 你的机器人 → 开发设置 |

填完点「**测试连接**」，显示绿字就通过了。

> AppSecret 是一次性的：重置之后旧密钥立刻失效，必须重新复制粘贴。

### 2. 获取群 ID

点「**获取群 ID**」按钮，然后：

1. 把机器人拉进你要推送的 QQ 群
2. 在群里 **@机器人** 随便发一句话（例如「@机器人 你好」）

ID 会自动抓取并填入，显示「已获取 ✓」即可。

> QQ 的群 ID 不是群号，只能这样从群消息事件里抓，软件已自动完成。

### 3. 启动

回到「推送」页点「**启动**」，程序就会按时抓取、翻译、推送。

## 开机自动运行

「设置」页勾选：

- **开机自动启动** —— 下次开机自动打开本程序
- **启动后自动开始推送** —— 打开即自动开始推送，不用再点启动

两个都勾上，就是「开机全自动」：开机 → 自动打开 → 自动推送到群。

## 可调参数（设置页）

| 参数 | 说明 | 推荐 |
|---|---|---|
| 推送间隔 | 多久跑一轮 | 60 分钟 |
| 每日上限 | 一天最多推几条 | 30 |
| 重要性门槛 | 数字越大越挑剔 | 3 |
| 优先窗口 | 只先看 N 小时内的新闻 | 2 小时 |
| 配图开关 | 是否附带新闻配图 | 开 |

**时效规则**（优先级高于重要性）：先用「优先窗口」内的新闻；这一层没有，才放宽到「当日」；跨日旧闻一律不推；确认不了发布时间的一律不用。真的没有内容时，会明确说「暂时没有最新新闻」，绝不拿旧闻充数。

## 常见问题

**提示「AppID 或 AppSecret 不正确」**
密钥过期或复制错了。去 QQ 开放平台重新复制。

**提示「主动消息额度已用尽」**
群资料页 → 机器人 → 打开「接收机器人主动消息」。这是 QQ 的限制，不是程序问题。

**群 ID 抓不到**
确认机器人确实在群里；必须 **@机器人** 发消息，只是普通聊天不算。

**没收到新闻**
看「日志」页。若显示「最近 N 小时内没有符合条件的新进展」，说明确实没有新消息。可以把间隔调短，或把优先窗口调大。

## 数据存放位置

```
%APPDATA%\中东要闻推送\
├── config.json      配置（密钥加密后保存）
├── state.json       推送记录、每日计数
├── logs\            按天存放的运行日志
└── reports\         推送过的简报存档
```

程序换位置、升级版本，已填的密钥都不会丢。

## 从源码运行 / 打包

需要 Python 3.10+（自带 tkinter）。

```bash
# 直接运行（源码模式）
python main.py

# 命令行跑一轮
python main.py --run          # 抓取并推送
python main.py --dry-run      # 试跑，只看内容不发送

# 打包成单文件 exe
python -m pip install pyinstaller pillow
python -m PyInstaller build.spec --noconfirm --clean
# 产物：dist/中东要闻推送.exe
```

Windows 上双击 `打包.bat` 也可以一键完成打包。
